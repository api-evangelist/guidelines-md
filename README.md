## Overview

`guidelines.md` is a project-level Markdown file consumed by JetBrains' Junie AI coding agent. It lives at `.junie/guidelines.md` in a repository and supplies persistent context, project conventions, build and test commands, and coding standards that Junie should follow across sessions.

This repository tracks the guidelines.md format as an AI-agent configuration standard alongside peers like `AGENTS.md`, `CLAUDE.md`, and `.cursorrules`.
